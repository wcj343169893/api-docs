簡介

本平台為 Worky 提供第三方發佈工作的整合方案，提供第三方平台快速、安全的串接。當商家完成驗證流程後，系統將自動通知商家並完成帳號建立確認並可開始進行發佈工作。 本文件說明如何透過 API 串接平台各項功能，包含發佈工作、帳號建立等模組。

如對本文件有任何疑問，請聯繫技術支援團隊。所有 API 均需使用 HTTPS，並在 Header 中帶入有效的 Authorization Token。

工作發佈 API › 發佈工作

發佈工作

POST /employer/shop/job/publish
發佈工作至 Worky 平台。支援全新發佈或由範本工作轉為發佈。商家帳號必須已完成登入驗證（具備有效 Access Token）才可呼叫此 API。
需帶入 Access Token（Bearer）於 Authorization Header。全新工作請將 job_sn 傳入空字串。

Body 參數（必填）

參數名稱類型必填說明
shop_idint必填店鋪 ID，例如 110123
job_snstring(14)必填工作單號，全新工作傳入空字串 ""，修改工作傳入既有單號
job_type_level1int必填工作類型階層1 ID
job_type_level2int必填工作類型階層2 ID
job_type_level3int必填工作類型階層3 ID
start_date_listarray必填工作開始日期清單（YYYYMMDD 格式），例如 [20231013, 20231014]。修改工作時僅支援單日。
start_time_periodstring(5)必填工作開始時段（HH:MM），例如 08:00
end_time_periodstring(5)必填工作結束時段（HH:MM），例如 12:30
work_minutesint必填實際工作時間（分鐘），例如 240
rest_minutesint必填休息時間（分鐘），例如 30
recruit_countint必填招募人數，例如 10
hourly_wageint必填時薪，例如 1000
city_idint必填縣市編號（type=1 的 id）
district_idint必填區域編號（type=2 的 id）
addressstring必填工作地址
labor_insurance_deduction_typeint必填勞保自付額代扣類型：1=不由平台代扣、2=臨時工、3=部分工時
payment_method_idint必填付款方式 ID：1=信用卡、3=ATM、5=AFTEE 先享後付
emergency_contact_phonestring必填緊急聯絡電話

Body 參數（選填）

參數名稱類型說明
match_target_favorint是否只媒合給最愛夥伴：0=否、1=是
cover_photostring封面圖片 URL（空字串表示無封面）
photosarray環境照片 URL 清單（可空陣列）
descriptionstring工作說明（可空字串）
remarksstring備注（可空字串，最多 700 字）
workflowstring工作流程說明
teachingstring教學影片，JSON 字串格式 [{"title":"...","link":"..."}]
contact_timestring聯絡時間，例如 14:00-18:00
custom_namestring工作自訂名稱（最多12字）
skill_tagsarray技能標籤，最多3個，例如 [{"id":9,"text":"技能1"}]
benefit_tagsarray福利標籤，最多3個，例如 [{"id":11,"text":"福利1"}]
confirm_itemarray確認事項清單
coupon_id_listarray優惠券 ID 清單
is_double_salaryint是否雙薪：0=否、1=是
origin_job_snstring來源工作單號（工單編輯時必須帶入）

成功回應欄位

欄位名稱類型說明
resultboolean發佈結果，true 表示成功
job_sn_listarray發佈成功的工作單號清單，例如 ["16928729060001"]

常見錯誤情境

情境說明
Token 無效或過期重新登入取得新的 Access Token
shop_id 不存在或無權限確認 shop_id 是否屬於目前登入商家
工作日期不合法日期需符合平台限制（需在未來一定天數內，且符合最短發佈間隔）
超過每日發佈上限確認每日發佈工作數量是否已達上限

成功回應欄位

欄位名稱類型說明
countint工作總數

items[].job_snstring工作單號

items[].end_atint工作結束時間戳
items[].statusint工作狀態
items[].hourly_wageint時薪
items[].cover_photostring封面照 URL

工作發佈 API › 取消工作

取消工作

POST /employer/shop/job/cancel
取消已發佈的工作。取消後工作狀態將變更為「已取消」，已媒合的打工夥伴將收到通知。注意：取消工作可能產生罰金，請先確認相關規範。
需帶入 Access Token（Bearer）於 Authorization Header。

Body 參數

參數名稱類型必填說明
job_snstring必填工作單號，例如 16928729060001
cancel_reasonint必填取消原因代碼

成功回應欄位

欄位名稱類型說明
resultboolean取消結果，true 表示成功

請求範例

JSON Request
// POST /employer/shop/job/cancel
{
  "job_sn": "16928729060001",
  "cancel_reason": 1
}

回應範例

JSON Response
{
  "result": true
}

start_atint工作開始時間戳
end_atint工作結束時間戳

recruit_countint招募人數
recruited_countint已招募人數
recruit_deadlineint招募截止時間戳

Webhook 通知 › 交易結果通知

交易結果 Webhook 通知

POST {your_notify_url}
當交易狀態發生變更時，平台將主動以 POST 方式推播通知至商家設定的 notify_url。商家需在 5 秒內回傳 HTTP 200 並包含 {"code":"0000"} 以確認收到。若未收到確認，平台將每隔 5 分鐘重試，最多重試 5 次。
Webhook 為平台主動推播，非商家呼叫。商家需提供可對外接收 HTTPS POST 的端點。

通知推播欄位

欄位名稱類型說明
event_typestring事件類型（TRANSACTION_SUCCESS / TRANSACTION_FAILED）
transaction_idstring平台交易識別碼
order_idstring商家訂單編號
statusstring交易狀態
amountinteger交易金額
timestampstring事件發生時間（ISO 8601）
signaturestringHMAC-SHA256 簽章（供驗證使用）

簽章驗證說明

為確保通知來源為本平台，商家應驗證 signature 欄位。

簽章計算方式：
1. 將 Body 中除 signature 以外的欄位，依 key 字母排序後串接為 key=value&key=value...
2. 使用商家的 Secret Key（由平台提供）以 HMAC-SHA256 計算雜湊
3. 將計算結果（HEX 小寫）與收到的 signature 比對，一致即為有效

Python 驗證範例
import hmac, hashlib
 
def verify_webhook(payload: dict, secret: str, received_sig: str) -> bool:
    fields = {k: v for k, v in payload.items() if k != "signature"}
    sorted_str = "&".join(f"{k}={v}" for k, v in sorted(fields.items()))
    computed = hmac.new(secret.encode(), sorted_str.encode(), hashlib.sha256).hexdigest()
    return hmac.compare_digest(computed, received_sig)

❓ 常見問題

如何申請 API 測試環境（Sandbox）帳號？
請來信至 api-support@worky.tw，信件主旨請標明「Sandbox 申請」，並附上公司名稱、負責人姓名及聯絡電話，我們將於 2 個工作日內完成審核並寄出帳號資訊。
Access Token 失效後如何重新取得？
Access Token 有效期為 24 小時。到期後請重新呼叫 POST /v1/auth/token 取得新 Token，建議在 Token 到期前 5 分鐘主動更新，以避免服務中斷。
Webhook 通知沒有收到，應如何排查？
請依序確認：(1) Notify URL 是否可對外接受 POST 請求；(2) 伺服器是否在 5 秒內回傳 HTTP 200 及 {"code":"0000"}；(3) 防火牆是否允許 Worky 伺服器 IP 範圍。如仍無法解決，請提供 transaction_id 至技術信箱，我們可協助查詢推播紀錄。
Rate Limit 上限是多少？可以提升嗎？
預設 Rate Limit 為每分鐘 60 次請求（per IP）。如業務需求超過此限制，可聯繫商務合作信箱申請提升方案，企業合作夥伴最高可提升至每分鐘 600 次。
API 文件版本更新時，如何收到通知？
目前可至本文件「更新日誌」頁面查看最新版本資訊。如需主動通知服務，請來信登記電子信箱，後續重大更版時將寄送 Email 通知。
